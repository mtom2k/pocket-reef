# Architecture

Pocket Reef is a Godot 4.7 project (GDScript, Compatibility renderer) with a small Objective-C GDExtension for macOS-specific behaviour. All art is generated by Python scripts. The tank's water, floor and glass are drawn at runtime.

```
┌──────────────────────── Godot process ────────────────────────┐
│  TankState (autoload)  settings · fish roster · decor · save  │
│        ▲  signals: settings_changed, roster_changed, …        │
│  main.gd (root Node2D = the tank window)                      │
│   ├─ layers: water · DecorLayer · gravel · fish · food ·      │
│   │          BubbleLayer · glass frame · overlay              │
│   ├─ _tick(): the tank's animation clock                      │
│   ├─ input: feed · drag window · resize · decorate            │
│   ├─ Tray (menu bar / tray icon + context menu)               │
│   ├─ TankAudio (bubbler loop + pops)                          │
│   └─ SettingsWindow (native window, UITheme)                  │
│                                                               │
│  native/macos_agent (GDExtension, Objective-C)                │
│   ├─ menu-bar-only activation policy (exported app only)      │
│   ├─ occlusion → env POCKETREEF_OCCLUDED                      │
│   └─ App Nap / timer-coalescing opt-out                       │
└───────────────────────────────────────────────────────────────┘
```

## Scripts

| File | Responsibility |
|---|---|
| `tank_state.gd` | **Autoload, the single source of truth.** Holds settings, fish, decor and tank size; handles save/load (`user://tank.json`), migrations, stocking and capacity rules, and emits signals. |
| `main.gd` | The tank window: builds the layers, runs the clock (`_tick`), handles input, window size and position, the power state, and occlusion polling. |
| `fish.gd` | One fish. Decides 10× a second and moves on every tick. Habits: `swim`, `bottom`, `crawl`, `glass`, plus an optional `host` (a decoration it lives near: clownfish → anemone, royal gramma → rock arch) and `air` (`false` stops a bottom dweller swimming up to breathe). |
| `food.gd` | A sinking flake. |
| `bubble_layer.gd` | All bubbles, drawn by a single node. |
| `decor_layer.gd` | Places decorations on the gravel; handles hit-testing, plant sway, bubble emitters and `find_type`. |
| `tank_renderer.gd` | Draws the water, the 7 floors and the glass frame for any tank size. Hash-based, so resizing is stable. |
| `species_db.gd` · `decor_db.gd` | Static catalogues of species (habit, speed, bioload, depth band, variants) and decorations (sway, sink, bubbles, categories). The species order is the order of the "Add fish" menu: freshwater, bottom dwellers, oddballs, reef, then invertebrates. |
| `settings_window.gd` · `ui_theme.gd` | The native settings window (Fish, Decor, Tank and About tabs) and its theme. It is responsive: `_reflow()` picks grid column counts from the width, label/control rows stack below 600 logical px, and zoom is 0.9–1.35× of the design size. |
| `tray.gd` | Menu-bar/tray `StatusIndicator` plus a right-click `PopupMenu`. |
| `tank_audio.gd` | Looping bubbler and occasional pops. |
| `login_item.gd` | Open at login: a LaunchAgent plist on macOS, the `HKCU\…\Run` key on Windows. |

## Timing model

This is the most important thing to understand.

- **The loop:** `OS.low_processor_usage_mode = true` and `Engine.max_fps = 0`. Godot polls input every `ACTIVE_SLEEP_USEC` (6.9 ms), or every `IDLE_SLEEP_USEC` (33 ms) when hidden or covered, and **redraws a window only when something in it changed.**
- **The tank's clock:** `main.gd _process` adds up time and calls `_tick(dt)` at `TankState.target_fps()` (12, 20 or 30). `_tick` steps the fish, food, bubbles and plant sway. Between ticks nothing changes, so nothing is drawn.
- **The UI** (settings window, popups) redraws as soon as it changes, unaffected by the tank's frame rate.
- **Hidden or covered:** nothing steps, so 0 frames are drawn and hunger is added up in batches.
- **Rules:**
  - Never animate in `_process` or with `TIME` in a shader; add a step to `_tick` instead. `TIME` forces constant redraws.
  - Never use `Engine.max_fps` to save power (see DECISIONS #10).

## Data and save format

`user://tank.json` lives in `~/Library/Application Support/Pocket Reef/` on macOS and `%APPDATA%/Pocket Reef/` on Windows.

```jsonc
{
  "format": 2, "app_version": "0.5.0", "saved_at": 1791930000.0, "next_id": 42,
  "settings": { "scale": 3, "volume": 0.4, "muted": false, "always_on_top": true,
                "tank_visible": true, "window_position": [x, y], "tank_width": 192,
                "tank_height": 120, "performance": "balanced", "substrate": "gravel" },
  "fish":  [{ "id": 1, "species": "oranda", "variant": "tricolor", "name": "Mochi", "hunger": 0.3 }],
  "decor": [{ "id": 7, "type": "anemone", "x": 0.62, "flip": false }]   // x = fraction of width
}
```

**Migrations run in `TankState`:**
- Format 1 (v0.1) saves get the starter decorations.
- A save from the old "Fishtank" data folder is copied over once (`migrate_legacy_save`).

Fish dictionaries are shared by reference with the `Fish` nodes, so hunger persists without extra plumbing.

## Rendering

The tank is drawn at 96×72 up to 256×144 "tank pixels" (in 8 px steps), then scaled by a whole number: zoom (2–5×) times the screen's scale. Window sizes on macOS are in **pixels**.

**Draw order** (`main._build_layers`), back to front:
1. Water
2. Decorations (taller pieces behind)
3. Gravel
4. Fish (`glass`-habit fish use `z_index` 2)
5. Food
6. Bubbles
7. Glass frame (gold in decorate mode)
8. Overlay (hover outline, resize grip)

`shaders/swim.gdshader` bobs pixel columns, more toward the tail; `sway.gdshader` shifts pixel rows of plants. Both take their phase or time from the tank's clock.

## Art pipeline

```
tools/spritegen/species.py  ASCII silhouettes + colour ramps ┐
tools/spritegen/decor.py    ASCII + procedural pieces        ├─ render.py (shared lighting/outline rules)
tools/spritegen/palette.py  ENDESGA 32                       ┘        → art/**/*.png (+ previews)
uv run --with pillow tools/spritegen/export_godot.py         # regenerates everything the game uses
```

A colour morph is a set of ramps (`body`, `belly`, `p1`, `p2`, `fin`, optional `tail`, `wen`, `patches`, `eye`). A morph whose markings differ, not just its colours (panda corydoras, leopard danio, sunset platy), also brings its own `shape`: the species silhouette with markings painted on by `_mark()` in `species.py`.

Rules are in [docs/style-guide.md](docs/style-guide.md).

## Native plugin (macOS)

`native/macos_agent/agent.m` is a minimal GDExtension written against the raw C API, with no godot-cpp. When initialised at scene level it:
1. Switches the exported bundle (`com.pocketreef.app`) to the accessory activation policy, so it has no Dock icon.
2. Watches window-visibility (occlusion) notifications and sets the `POCKETREEF_OCCLUDED` environment variable, which `main.gd` polls.
3. Opts out of App Nap and timer coalescing, except inside the Godot editor.

`build.sh` produces a universal dylib, which is committed so the project runs without Xcode.

| | macOS | Windows |

## Tests

| Test | What it covers |
|---|---|
| `tests/smoke_test.tscn` | Boots the real tank and drives everything (115 checks): settings, species (every species spawns, every morph has a sprite, the habits work), decor, floors, resize, input, timing (frames drawn per mode), hidden and covered states (including real screen captures), save and migrations. Refuses to run against the real save file. |
| `tests/settings_layout.tscn` | Opens the settings window at 420×400 up to 1200×900 and fails if any control on any tab sticks out past the window. Can save screenshots with `--shots=DIR`. |
| `tests/responsiveness.sh` | Hidden tank must answer Apple Events in under 600 ms. Guards against the v0.2.2 menu-bar freeze. |
| `tests/perf_probe.tscn` | CPU, memory, frames drawn and loop rate per scenario (`--scenario`, `--performance`, `--zoom`, `--sleep-usec`). |
